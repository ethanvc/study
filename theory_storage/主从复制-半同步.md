## mysql source崩溃，重启后未同步数据被提交了
设置实例A为半同步的source。

执行命令：`create database testdb2;`

此时，指令卡在：

```
| 11 | root            | localhost | NULL | Query   |   23 | Waiting for semi-sync ACK from replica | create database testdb2 |
```

重启mysql，发现testdb2创建成功，这个不符合如下配置的行为：

```
SET GLOBAL rpl_semi_sync_source_wait_point = 'AFTER_SYNC';
```

分析原因。

mysql崩溃重启后，会根据binlog修复数据，从而应用了数据，此时，source比replica多数据。
